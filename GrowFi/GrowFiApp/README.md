# GrowFi iOS App

This folder contains the SwiftUI implementation of the six Figma screens:

- Home
- Accounting calendar
- Accounting pocket
- Finance market
- AI stock picker sheet
- Profile

Open `GrowFi.xcodeproj` on macOS with Xcode 15.4 or newer, then run the `GrowFi` scheme on an iOS 17+ simulator.

The current Windows workspace does not include `xcodebuild` or Swift tooling, so final compile and simulator screenshot verification must happen in Xcode.
